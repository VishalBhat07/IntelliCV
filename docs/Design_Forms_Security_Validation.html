Design of Forms, Security and Validation

1. Form Design

1.1 Login Form

The login form collects user credentials with the following fields:

  • Email Address: Text input with type="email" for browser-level validation
  • Password: Masked input with type="password" for security
  • Submit Button: Triggers authentication with loading state indication

1.2 Registration Form

The signup form is organized into logical sections:

  • Personal Information: First Name, Last Name (both required)
  • Contact Details: Email Address, Password (minimum 8 characters)
  • Professional Goals: Target Job Title (optional)

1.3 Resume Editor Form

A comprehensive form with multiple sections:

  • Personal Info: Name, Title, Email, Phone, Location
  • Summary: Textarea for professional summary
  • Experience: Dynamic list with Position, Company, Duration, Description
  • Education: Institution, Degree, Year, GPA
  • Skills: Technical Skills, Tools, Soft Skills (comma-separated)
  • Projects: Title, Description, Technologies, Link
  • Certifications: Title, Issuer, Date

2. Security Implementation

2.1 Password Hashing

User passwords are hashed using Bcrypt with a salt factor of 10 before storage:

const bcrypt = require("bcrypt"); // Registration - Hash password const hashedPassword = await bcrypt.hash(password, 10); // Login - Compare passwords const isMatch = await bcrypt.compare(inputPassword, storedHash);

2.2 JWT Authentication

JSON Web Tokens are used for stateless authentication:

const jwt = require("jsonwebtoken"); // Generate token on login const token = jwt.sign( { user_id: user.user_id }, process.env.JWT_SECRET, { expiresIn: "7d" } ); // Verify token on protected routes const decoded = jwt.verify(token, process.env.JWT_SECRET);

2.3 Protected Routes

API endpoints are protected using authentication middleware:

module.exports = (req, res, next) => { const token = req.headers.authorization?.split(" ")[1]; if (!token) { return res.status(401).json({ msg: "No token provided" }); } try { req.user = jwt.verify(token, process.env.JWT_SECRET); next(); } catch (err) { return res.status(403).json({ msg: "Invalid token" }); } };

2.4 SQL Injection Prevention

Sequelize ORM is used for all database operations, which automatically parameterizes queries:

// Safe query using Sequelize const user = await User.findOne({ where: { email: email } }); // Direct SQL with parameterized query const [results] = await sequelize.query( "SELECT * FROM users WHERE email = ?", { replacements: [email] } );
