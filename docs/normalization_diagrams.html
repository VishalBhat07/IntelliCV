1. First Normal Form (1NF)

1NF Violations (Multivalued Attributes)

The ER Diagram contains Composite Attributes (e.g., Name) and Multivalued Attributes (e.g., Phone, Tech Stack, Keywords, Skills). In a direct relational mapping, these would violate 1NF if kept in a single table.
